# Validation

This folder contains checker tools, checker inputs, and validation outputs.

- `official_checker/` - external validity checker executable, its input files, and older corresponding validation result files.
- `independent_germany/` - independent coverage verification generated by `validation/tools/verify_selected_tower_solution.py`.
- `run_summaries/` - compact summaries/logs from the final optimization runs.
- `tools/` - validation helper scripts.
